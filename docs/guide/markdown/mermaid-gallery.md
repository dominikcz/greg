# Mermaid diagram gallery

Examples of the most common Mermaid diagram types rendered with Greg's built-in
`material` theme. Switch between light and dark mode to see both variants.
For the basics, see [Svelte components and Mermaid](./components-and-mermaid).

Greg follows Mermaid's defaults: the **neo** look and the automatic **ELK** layout.
